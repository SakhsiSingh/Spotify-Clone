# 🎵 Spotify Clone

A Spotify-inspired music player UI built to practice frontend web development. This project recreates the look and feel of Spotify with a dark interface, music controls, and a clean layout.

## ✨ Features

- 🎧 Spotify-inspired user interface
- 🌑 Dark-themed design
- 📚 Sidebar navigation
- 🎵 Music player section
- ⏯️ Playback controls and progress bar UI
- 🎨 Custom styling and scrollbar design
- 📱 Responsive design (if implemented)

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript


## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/SakhsiSingh/Spotify-Clone.git
```

### 2. Open the project folder

```bash
cd Spotify-Clone
```

### 3. Run the project

Open `index.html` in your browser.

If you're using Vite or another development server, run the appropriate command for your project instead.
